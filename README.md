# Balloon Darts Game

เกมปาโป่งหาเลขคู่/เลขคี่ รองรับทั้งโหมดสัมผัสและโหมด AR ผ่านกล้อง

## วิธีเล่น

- เปิดหน้า `index.html`
- เลือก **เล่นโหมดปกติ (สัมผัส)** หรือ **เล่นโหมด AR (เปิดกล้อง)**
- ปาโดนลูกโป่ง **เลขคู่** เพื่อทำคะแนน
- ลูกโป่งเลขคี่จะโดนหักคะแนน

## ไฟล์สำคัญ

- `index.html` — ไฟล์เกมหลัก
- `assets/cover.mp4` — วิดีโอหน้าแรก
- `assets/cover.jpeg` — ภาพปกวิดีโอหน้าแรก
- `correct.mp3` — เสียงตอนตอบถูก
- `wrong.mp3` — เสียงตอนตอบผิด

## หมายเหตุ

- โหมด AR ต้องอนุญาตการใช้กล้อง
- ถ้าเบราว์เซอร์บล็อกเสียงอัตโนมัติ อาจต้องมีการแตะ/คลิกครั้งแรกก่อนเสียงจะดัง
- หากย้ายไฟล์ asset ให้แก้ path ใน `index.html` ให้ตรง
